# The AI Artiste

A museum-style showcase of impressionist paintings generated by eight GPT-5 model variants through [Neon AI Gateway](https://neon.com/docs/ai-gateway/overview) — with branching, a house critic, and a public gallery on Vercel.

**Live:** [https://ai-impressionist-museum.vercel.app](https://ai-impressionist-museum.vercel.app)

---

## What this is

**The AI Artiste** is a small public demo for [Neon AI Gateway](https://neon.com/docs/ai-gateway/overview) and [Neon branching](https://neon.com/docs/introduction/branching).

One Neon project hosts the show. Each GPT-5 variant gets its own branch. Each variant receives an impressionist brief and composes a painting via the gateway’s OpenAI Responses `image_generation` tool. The frontend is a black-box museum: cream type, wall plaques, and a Neon badge in the corner.

Visitors get three tabs:

1. **Gallery** — a slideshow showroom. Plaques name the model as the artist, with wall text for each work.
2. **Critic's Verdict** — a playful house review: most beautiful, most transformative, and least adequate.
3. **Methodology** — how the show was built (gateway, branches, Next.js, Vercel).

### Authorship 

Image generation on Neon AI Gateway today routes through OpenAI GPT-5 variants and a shared renderer. The model is still the “artiste”: each variant interprets its own subject. Plaques credit the real model ID; Methodology explains the shared renderer.

## Stack

- **[Neon](https://neon.com)** — Postgres + AI Gateway + one branch per model  
- **[Neon AI Gateway](https://neon.com/docs/ai-gateway/overview)** — one Neon credential; no separate OpenAI key  
- **Next.js** — museum UI

## Run locally

```bash
git clone https://github.com/carlotas19/ai-impressionist-museum.git
cd ai-impressionist-museum
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Committed gallery images are enough to browse — no Neon credentials required just to view the site.

## Regenerate the art (optional)

Needs a Neon project that can call AI Gateway:

1. **Region:** `aws-us-east-2` (Ohio)  
2. **Plan:** paid (Launch / Scale / Enterprise)  
3. **Credential:** branch credential with scope `ai_gateway:invoke`  
4. **Env vars** in `.env.local` (see [`.env.example`](./.env.example))

```bash
python3 scripts/generate_art_http.py
# or: npm run generate
```

Optional Node helpers under `scripts/` (`generate-art.ts`, `setup-branches.ts`, `setup-db.ts`) need extra packages installed manually if you prefer that path.

> The gateway caps non-streaming responses near ~640 KB. The HTTP generator requests `quality: low` JPEGs to stay under that limit.

Docs: [AI Gateway overview](https://neon.com/docs/ai-gateway/overview) · [Models](https://neon.com/docs/ai-gateway/models) · [Responses / image generation](https://neon.com/docs/ai-gateway/openai-responses)
